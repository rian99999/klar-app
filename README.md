# KLAR App

KLAR 고객/예약/퍼스널컬러/메이크업 결과 관리 앱입니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://127.0.0.1:5173/`로 접속합니다.

## 인터넷 주소로 접속하기

방법이 두 가지 있습니다. 목적에 따라 고르세요.

| | A. 임시 주소 | B. 항상 켜진 주소 |
| --- | --- | --- |
| 준비물 | 없음 | 호스팅 서비스 가입 (Railway 등) |
| 비용 | 무료 | 월 5달러 안팎 |
| 내 컴퓨터 | **켜 두어야 함** | 꺼도 됨 |
| 주소 | 실행할 때마다 **바뀜** | 항상 같음 |
| 고객에게 결과지 링크 보내기 | 부적합 (주소가 바뀌면 링크가 죽음) | 적합 |

### A. 임시 주소 — 지금 바로, 무료

1. 먼저 비밀번호를 정합니다. (`.env.example` → `.env` 로 복사 후 `KLAR_PASSWORD` 수정)
   인터넷에 여는 것이므로 개발용 기본 비밀번호로는 실행되지 않습니다.
2. `인터넷주소-켜기.bat` 를 더블클릭합니다.
3. 검은 창에 나오는 `https://...trycloudflare.com` 주소가 사이트 주소입니다.
   휴대폰이나 다른 사람 컴퓨터에서 그 주소로 접속하면 됩니다.

창을 닫으면 주소도 사라집니다. 다시 실행하면 **다른 주소**가 나옵니다.

### B. 항상 켜진 주소 — Railway

`railway.json` 에 빌드·실행·헬스체크 설정이 들어 있어 저장소를 연결하면 바로 배포됩니다.
**직접 하실 일은 두 가지뿐입니다.**

1. **Variables 에 `KLAR_PASSWORD` 추가** — 원하는 접속 비밀번호를 넣습니다.
   이게 없으면 앱 대신 "비밀번호를 아직 정하지 않았습니다" 안내 화면이 뜹니다.
   (서버가 죽지 않으니, 값만 넣으면 바로 앱이 열립니다.)
2. **Volume 을 `/data` 에 연결** — 클라우드 컨테이너는 배포·재시작할 때마다 파일이
   초기화됩니다. 볼륨을 붙이지 않으면 **고객 기록이 사라집니다.**
   `/data` 에 붙이기만 하면 저장 위치는 서버가 알아서 잡습니다.

나머지는 자동입니다.

| 변수 | 필요한가요 | 설명 |
| --- | --- | --- |
| `KLAR_PASSWORD` | **필수** | 접속 비밀번호 |
| `KLAR_ADMIN_PASSWORD` | 선택 | 직원과 관리자 권한을 나눌 때만 |
| `KLAR_SESSION_SECRET` | 불필요 | 없으면 서버가 만들어 저장소에 보관합니다 |
| `KLAR_DB_PATH` | 불필요 | `/data` 볼륨이 있으면 자동으로 잡습니다 |
| `NODE_ENV` | 불필요 | 호스팅 환경을 자동으로 알아봅니다 |

볼륨을 붙이더라도 가끔 **데이터 백업 · 복원**(아래 설명)으로 파일을 받아 두시는 것을
권합니다.

### 사이트가 안 열릴 때

| 보이는 증상 | 원인 | 해결 |
| --- | --- | --- |
| "비밀번호를 아직 정하지 않았습니다" 화면 | `KLAR_PASSWORD` 없음 | Variables 에 추가 |
| 502 / Application failed to respond | 앱이 시작되지 못함 | 배포 로그의 맨 아래 줄 확인 |
| 접속은 되는데 기록이 사라짐 | 볼륨 없음 | Volume 을 `/data` 에 연결 |
| 새로고침하면 로그인 풀림 | 예전 버전 | 이 버전부터는 자동으로 유지됩니다 |

## 접속 비밀번호 정하기

앱을 열면 비밀번호를 물어봅니다. 비밀번호는 아래 방법으로 정합니다.

### 내 컴퓨터에서 쓸 때

1. 이 폴더 안의 `.env.example` 파일을 복사합니다.
2. 복사한 파일의 이름을 `.env` 로 바꿉니다. (앞의 점까지 포함해서)
3. 메모장으로 열어 따옴표 안을 원하는 비밀번호로 고치고 저장합니다.

```text
KLAR_PASSWORD="원하는비밀번호"
KLAR_SESSION_SECRET="아무-긴-문자열이나-넣으세요-1234567890"
```

`.env` 파일은 GitHub에 올라가지 않습니다.

`.env` 를 만들지 않으면 개발용 비밀번호 `klar-dev` 로 열립니다. 혼자 쓰실 때는 그대로
두셔도 되지만, 인터넷에 올리실 거라면 반드시 정해 주세요.

### 인터넷에 올릴 때 (Railway 등)

`.env` 파일 대신 해당 서비스의 환경 변수 설정에 넣습니다. 필요한 변수는
[위 표](#b-항상-켜진-주소--railway)를 참고하세요. `KLAR_PASSWORD` 가 없으면 앱 대신
안내 화면이 뜹니다.

비밀번호는 서버에만 있으며 화면 쪽 파일에는 들어가지 않습니다. 예전의
`VITE_ADMIN_PASSCODE` 방식은 값이 그대로 노출되어 더 이상 사용하지 않습니다.

## 링크로 제품 불러오기

관리자 페이지 상단에 제품 페이지 주소를 붙여넣으면 제품명·브랜드·이미지·세부 품목(색상
옵션)을 자동으로 읽어 등록 칸에 채워 줍니다.

- 페이지가 공개하는 정보(Open Graph 태그, JSON-LD 상품 정보, 옵션 목록)를 읽습니다.
- 여러 장의 이미지 중 원하는 것을 골라 쓸 수 있고, 색상 옵션을 고르면 제품명 뒤에 붙습니다.
- 자동으로 저장되지 않습니다. 채워진 내용을 확인하고 직접 등록 버튼을 눌러야 저장됩니다.
- 자바스크립트로만 내용을 그리는 사이트나 봇을 차단하는 사이트에서는 정보를 일부만
  가져오거나 못 가져올 수 있습니다. 그럴 때는 직접 입력하시면 됩니다.

서버에서만 동작하며 로그인한 사용자만 사용할 수 있습니다. 내부망 주소(`localhost`,
사설 IP, 클라우드 메타데이터 주소)는 리다이렉트 경로까지 포함해 차단됩니다.

## 결과지 링크 보내기

고객 상세 페이지의 **고객 결과지 링크** 칸에서

- **공유하기** — 휴대폰의 공유 창(문자·카카오톡 등)이 열립니다. 공유 창이 없는 브라우저에서는
  등록된 연락처로 문자 앱이 열리고, 연락처도 없으면 링크가 복사됩니다.
- **링크 복사** — 주소만 복사합니다.
- **고객 화면 미리보기** — 고객이 보게 될 화면을 그대로 확인합니다.

## 데이터 백업 · 복원

관리자 페이지의 **데이터 백업 · 복원** 칸을 펼치면

- **내려받기** — 고객·예약·기록·제품 전체가 담긴 `klar-backup-날짜.json` 파일을 저장합니다.
- **불러오기** — 저장해 둔 파일을 골라 그대로 되돌립니다. 지금 데이터는 파일 내용으로 완전히
  바뀌므로, 되돌리기 전에 먼저 내려받아 두세요. 확인 창에서 바뀌는 건수를 보여 줍니다.

## 고객 결과지

`/result/:customerId`만 로그인 없이 열립니다. 고객이 이름과 연락처 뒷 4자리를 입력하면
서버가 대조한 뒤 **해당 고객의 기록과 진단 톤에 맞는 제품만** 내려줍니다. 다른 고객의
정보는 응답에 포함되지 않습니다.

## 서버 저장

`npm run dev`는 Express 서버와 Vite 화면을 함께 실행합니다. 앱 데이터는 자동으로 서버 API(`/api/state`)에 저장되며 기본 저장 파일은 아래 경로입니다.

```text
server/data/klar-db.json
```

저장 위치를 바꾸려면 `KLAR_DB_PATH` 환경 변수를 설정합니다.

운영 모드로 빌드 후 실행하려면:

```bash
npm run build
npm run start:prod
```
